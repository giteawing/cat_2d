# Как запустить Cat Portal Adventure 2D

Игра — чистый HTML5/JavaScript (Canvas 2D), без сборки и без зависимостей.
Кооператив на двоих идёт через собственный игровой сервер на Node.js (тоже без зависимостей).

## Вариант 1 — игровой сервер (рекомендуется, 1–2 игрока)

```bash
git clone <url репозитория>
cd cat_2d
npm run server         # server/index.mjs: http://localhost:8080 + WebSocket ws://localhost:8080/ws
```

Откройте в браузере **http://localhost:8080**. Первый, кто откроет страницу, — **Игрок 1 (рыжий кот)**: сессия
создаётся, стартует уровень. Второй открывший страницу (с другого компьютера — по адресу сервера, например
`http://192.168.1.10:8080`) — **Игрок 2 (чёрный кот)**: он появляется рядом с первым в том же уровне, ничего не
перезапускается. Третьему сервер ответит «занят». Другой порт / стартовый уровень: `node server/index.mjs 3000 0`.

- Один игрок играет ровно так же, как раньше. Когда подключается второй, **выход уровня открывается, когда на нём
  стоят оба кота**; отключился — правило снова одиночное, уровень продолжается.
- У каждого своя камера, свой прицел, своя пушка и своё туннелирование; мир (предметы, порталы, двери, плиты,
  лазеры, подарки) общий — всё, что делает один, видит другой. Подобранное оружие открывается обоим.
- Меню выбора уровня, `R` (рестарт) и «следующий уровень» общие: решение любого игрока применяется к сессии.
- Статус подключения — маленькая строка в правом нижнем углу страницы и метка «Игрок 2 …» в HUD.
- Клиент на другом сервере: `http://…/index.html?ws=ws://host:port/ws`; принудительно без сети: `?offline`.

Требования: Node.js 18+ (проверено на 22). `npm install` для самой игры/сервера не нужен.

## Вариант 1б — только статика (офлайн, один игрок)

```bash
npm start              # tools/serve.mjs на http://localhost:8080, без сервера сессии
```

## Вариант 2 — Python

```bash
cd cat_2d
python3 -m http.server 8080
```

и откройте http://localhost:8080.

## Вариант 3 — VS Code

Расширение **Live Server** → правой кнопкой по `index.html` → «Open with Live Server».

## Управление

| Клавиша | Действие |
|---|---|
| A / D или ← / → | ходьба |
| Shift | бег |
| Q (или F) | режим квантового туннелирования (после подбора на уровне 7): с разбега беги в потенциальный барьер — шанс пройти 25%, иначе упругий отскок. Пока режим включён, кот светится синим контуром |
| Space | прыжок (высота зависит от длительности нажатия) |
| W / ↑ | лестница вверх / посмотреть вверх |
| S / ↓ | присесть / лестница вниз / посмотреть вниз; S + Space — спрыгнуть с тонкой платформы; в воде — нырнуть (W — всплыть, Space у поверхности — выпрыгнуть на берег) |
| 1 | Gravity Gun |
| 2 | Portal Gun |
| Мышь | прицел (кот поворачивается и наводит пушку) |
| ЛКМ (Gravity Gun) | схватить / бросить удерживаемый предмет |
| ПКМ (Gravity Gun) | отпустить / толкнуть |
| ЛКМ / ПКМ (Portal Gun) | синий / оранжевый портал |
| E | взаимодействие (рычаги, кнопки, перевернуть зеркальный куб) / отпустить предмет |
| M | музыка вкл/выкл |
| Esc | пауза (продолжить, рестарт, музыка, громкость, выбор уровня) |
| R | перезапуск уровня |

**Геймпад** (стандартная раскладка, подключите до или во время игры): левый стик / крестовина — ходьба,
A — прыжок, X — бег, B/Y — взаимодействие, LB/RB — Gravity/Portal Gun, RT/LT — основное/второстепенное действие,
правый стик — прицел, Start — пауза, Back — рестарт.

Звук включается после первого нажатия клавиши или клика (ограничение браузеров).

## Прогресс

Сохраняется автоматически в `localStorage` браузера: открытые/пройденные уровни, подарки, секреты, настройки.
Сброс прогресса: на экране выбора уровня нажать **Shift + Delete**.

## Тесты и скриншоты (для разработки)

Автотесты гоняют игру без браузера (Node + `@napi-rs/canvas`):

```bash
cd tools && npm install && cd ..   # один раз
npm test                           # 188 проверок: физика, порталы, оружие, потенциальные барьеры и туннелирование, лазеры, зеркала и преломление, вода и плавучесть, мультиплеер (два кота в одном мире), прохождение уровня 1, sanity всех уровней
npm run test:net                   # 28 сетевых проверок: реальный сервер + два клиента (вход, ход второго, выход на двоих, отключение, реконнект, «занят», рестарт, меню и выбор уровня, гравипушка и бросок по сети, Q, локальная пауза)
npm run shots                      # скриншоты уровней в tools/out/
npm run walk                       # «живое» прохождение всех 13 уровней (мир 1, мир 2, мир 3): только клавиши и клики по видимым целям, все подарки собраны
```

## Частые проблемы

- **Пустая страница / ошибки CORS в консоли** — файл открыт напрямую (`file://`). Запустите через HTTP-сервер (см. выше).
- **Нет звука** — нажмите любую клавишу или кликните по канвасу; проверьте пункт «Музыка»/«Громкость» в меню паузы (Esc).
- **Порт занят** — `node server/index.mjs 8081` (или `node tools/serve.mjs 8081` для офлайна).
- **Второй игрок не видит первого** — оба должны открыть страницу с ОДНОГО сервера (`npm run server`); `npm start` сессию не создаёт.
- **«Сервер занят»** — в сессии уже два игрока; сессия освобождается через минуту после выхода обоих.
